Education and Projects

GRA 311 - Environment Design

Engine: Maya/Blender/Substance Painter 3D/ Unreal Engine 5

Course project revolved around developing a playable and navigable level from a potential finish game. For my level, I created an environment from 'Lodestar', a game concept I created set entirely on an island. Featuring a lighthouse and several other decaying buildings, Lodestar is intended to give off lonely, mysterious, and uneasy moods. Several assets were created by me, using the engines listed above, while the remaining came from CC0 sites, such as Fab.

GRA 201 - Intro to Digital Sculpting

Engine: Maya/ZBrush/Unreal Engine 5

Course project focused on developing a model from conception to game-ready asset. More specifically, I chose to model a simplified electrical box. I created a basic concept art, used effective workflow to model both low-poly and high-poly variants, sculpted finer details, and painted appropriate diffuse, specular, and normal maps.

GAM 415 - Graphics Game Engine

Engine: Unreal Engine 5 Blueprints/C++

Course project focused on procedural assets, such as terrain generation, image mirroring, and projectiles. More specifically, C++ scripting was used to generate random colors and decals upon projectile impact, a randomized terrain generator, and a teleporter which renders in real time the exit location. Maintained using feature-branching workflow on Github.

GAM 312 - Gameplay System Development

Engine: Unreal Engine 5 Blueprints/C++

Course project focused on creating a short survival game. Requirements consisted of harvestable resources, roaming AI, custom and sculpted terrain, crafting and inventory menu, and a basic player controller. Project also required the use of UE5 C++ scripts. Most additions were created using C++ classes and enhanced with UE5 blueprints. Maintained using feature-branching workflow on Github.

GAM 305 - Digital Game Development

Engine: Unreal Engine 5 Blueprints

Course project focused on collaborating with three other students to make an objective-oriented game of their choosing. Our group settled on a short third-person horror explorer set inside a haunted toy store. The course required the use of feature-branching workflow on Github. Specifically, I had the role of Systems Developer- I programmed the player controls, AI movement, weapons/tools, pickups, and menu systems.

GAM 303 - Design of Virtual Game Environment

Engine: Unreal Engine 5 Blueprints

Course project focused on fundamental ideas of virtual environments. Students were given several game options to focus on. In my case, I opted for a 2.5D platformer with intractable enemies, doors, and pickups.

GAM 207 - Info Tech and Digital Games

Engine: Unreal Engine 5 Blueprints

Course project focused on learning the basics of game implementations, such as obstacles, AI, and pickups. For my project, I created a first-person shooter within an enclosed arena. Enemy AI roam and shoot targets nearby. Health pickups are scattered around the map on timers.
